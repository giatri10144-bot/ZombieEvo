# ZombieEvo

Zombie Evolution addon for Minecraft Bedrock Edition.

## Version
0.1.0

## Target
Minecraft Bedrock 1.26.30+

## Features (v0.1)

- Core addon system
- Configuration system
- Data storage system
- Debug system

## Planned Features

- Zombie evolution
- Day zombie spawning
- Zombie equipment
- Blood Moon
- Horde Night
- Special zombies
- Advanced AI
